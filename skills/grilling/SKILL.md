---
name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
---

Interview the user relentlessly about every aspect of the topic until you reach a shared understanding. Walk down each branch of the decision tree. Resolve dependencies between decisions one by one. For each question, provide your recommended answer.

Ask exactly one question in each response. Wait for the user's answer before you ask the next question.

Keep each question and recommended answer concise. Write all interview output in ASD-STE100 Simplified Technical English.

If a fact can be found by exploring the environment, find it instead of asking the user. The decisions are the user's. Put each decision to the user and wait for the answer.

Do not act on the result until the user confirms that you have reached a shared understanding.
